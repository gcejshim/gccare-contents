> 만든 사람: UX팀 심은진 · 2026-11-15

> 이 문서는 샘플에 없는 경우를 판단하는 기준이에요. **샘플과 이 문서가 다르면 샘플이 맞아요.**

## 0. 쓰는 방법

1. `consent-sample.html`을 열어 모양과 동작을 확인해요.
2. 파일 안 `<style>`의 **1. 디자인 토큰**, **2. 컴포넌트**, **3. 도구 상단 바**를 그대로 복사해서 써요. **4. 샘플 보기 화면**은 전달용이라 필요 없어요.
3. 약관 항목은 `<script>`의 `TERMS` 배열만 바꾸면 돼요.
   ```js
   {id:'service', required:true, label:'서비스 이용약관'}
   ```
4. AI(Claude, ChatGPT 등)로 만들 때는 **이 문서와 HTML 파일을 같이 첨부**하고 "이 디자인 기준과 샘플 그대로 만들어 줘"라고 요청하세요.

## 1. 화면 구성 (모바일 390 기준)

위에서부터 이 순서예요. 순서를 바꾸지 않아요.

1. **제목**: 두 줄 이내 (예: 서비스 이용을 위해 / 약관에 동의해 주세요)
2. **설명**: 한 줄, 회색
3. **전체 동의 카드**
4. **약관 줄 목록**: 필수 먼저, 선택은 뒤로
5. **안내·오류 문구**: 버튼 바로 위, 필수가 빠졌을 때만 빨간색으로 나타남
6. **하단 버튼**: 화면 아래 고정
7. **약관 보기 바텀시트**: 줄 오른쪽 `›`을 누르면 열림

## 2. 디자인 토큰

**색 — 어떠케어 앱 디자인 시스템 전체를 써요** (Figma Foundation › Color). 메인은 **녹색**이에요.

샘플 HTML의 `:root` 맨 위에 디자인 시스템 색이 **전부** 들어 있어요. 이 화면에 없는 상태(성공·주의·정보 등)가 필요하면 여기서 골라 써요.

- **Global Token (모든 색 단계)**: `--{색}-{단계}` 모양. 예: `--careGreen-500`, `--careRed-500`, `--neutral-900`
  - neutral · coolNeutral (0~900), careGreen · careBlue · careRed · careYellow · careOrange (10~900), volcano · lime · cyan · blue · purple · magenta (10~900), common white · black
- **Alias Token (역할 이름)**: 되도록 이 이름으로 써요.

## 3. 컴포넌트와 상태

**전체 동의 카드**
- 꺼짐: 바탕 `bg-alt`, 동그라미 테두리 `line-accent`
- 켜짐: 바탕 `green-10` + 테두리 `green-50`, 동그라미 `brand-primary` 채움 + 흰 체크
- 카드 전체가 누르는 영역이에요.

**약관 줄**
- 왼쪽 체크 표시(선만), 꺼짐 `line-accent` → 켜짐 `brand-primary`
- `[필수]`는 `brand-strong`, `[선택]`은 `text-sub`, 둘 다 SemiBold 600
- 체크와 글자는 한 버튼(누르는 영역 하나), `›`는 따로 누르는 버튼
- 글자가 두 줄이 되면 체크는 **첫 줄에 맞춰** 위쪽 정렬, `›`도 첫 줄 높이에

**하단 버튼**
- 늘 켜져 있어요: 바탕 `brand-primary`, 글자 흰색
- 눌림: 바탕 `brand-strong`

**안내·오류 문구**
- 필수를 다 고르지 않고 버튼을 누르면 버튼 위에 나타나요: ⓘ 아이콘 + "필수 항목에 모두 동의해 주세요." (14 Medium, `error`)
- 빠진 항목의 `[필수]` 글자도 `error` 빨간색으로 바뀌어요.
- 필수를 다 고르면 문구와 빨간색이 바로 사라져요.

**약관 보기 바텀시트**
- 뒤 화면은 50% 어둡게, 어두운 곳을 누르면 닫힘
- 위에 손잡이, 제목 + 닫기(X), 본문은 회색 상자 안에서 스크롤
- 맨 아래 [동의하기] → 그 항목을 체크하고 닫힘

**누를 때·키보드**
- 누르는 동안 살짝 흐려짐(투명도 0.7)
- 키보드 포커스는 `brand-primary` 2px 테두리

## 4. 동작 규칙

1. **전체 동의**를 누르면 모든 항목이 켜지고, 다시 누르면 모두 꺼져요.
2. 항목을 하나씩 다 켜면 **전체 동의도 자동으로 켜지고**, 하나라도 끄면 꺼져요.
3. 하단 버튼은 늘 누를 수 있어요. **필수가 빠졌으면** 다음으로 가지 않고 빨간 안내를 보여 줘요. 선택 항목은 상관없어요.
4. 시트의 [동의하기]는 그 항목만 켜요.

---

## 5. 샘플에 없는 경우

- **항목이 많을 때(6개 이상)**: 목록 부분만 스크롤하고, 하단 버튼은 고정
- **선택 항목 안에 세부 항목(앱 푸시·문자·이메일)이 있을 때**: 줄 아래에 들여쓰기(왼쪽 36) 14 크기 체크 줄로. 세부를 하나라도 켜면 위 항목도 켜짐
- **약관 본문이 외부 링크일 때**: 시트 대신 새 화면으로 열어도 되지만, `›` 위치와 모양은 같게
- **PC 화면**: 가운데 폭 390 그대로, 바깥은 `bg-alt` 바탕

---

## 6. 하지 말 것

- 기본 브라우저 체크박스(작은 네모) 쓰지 않기
- 항목마다 다른 화살표·링크 글자([보기], [자세히]) 섞지 않기 → 항상 `›` 하나
- [필수]·[선택]을 같은 색으로 쓰지 않기
- 그라데이션·그림자·일러스트 같은 장식 넣지 않기 (상단 바 제외)
- 빨간색을 오류·경고가 아닌 곳(강조, 장식)에 쓰지 않기

## 7. 도구 상단 바 (AX Studio와 같은 모양)

도구 화면을 만들 때는 맨 위에 이 바를 그대로 써요. 샘플 파일 맨 위에 있어요.

- 높이 62, 바탕은 남색 #031552 위에 블루·그린 빛이 은은하게 번지는 모양
- **왼쪽**: GC Care 로고(높이 18) | 도구 이름 `AX Studio · 약관동의` (15 SemiBold, 흰색)
- **가운데 왼쪽**: `◀ 어떠케어 ▶` 고르는 칸 (반투명 흰 바탕, 모서리 10)
- **오른쪽**: 파일 버튼들 (높이 34, 모서리 8, 반투명 흰 바탕 + 흰 테두리 22%, 글자 13)
- 버튼 이름과 개수는 도구 기능에 맞게 바꿔도 되지만, **모양과 위치는 그대로**

텍스트 수정

수정 방법

  1. 화면 왼쪽 편집 패널에서 수정할 섹션의 제목 또는 본문 텍스트를 클릭합니다.
  2. 내용을 직접 입력하면 오른쪽 미리보기에 실시간으로 반영됩니다.
  3. 줄바꿈은 Enter, 단락 구분은 빈 줄로 처리합니다.
수정 후 반드시 STEP 5 저장을 진행해야 변경사항이 유지됩니다. 브라우저를 닫으면 미저장 내용은 사라집니다.

3

이미지 생성 ChatGPT GPT

카드뉴스 이미지는 두 종류로 구분됩니다. 동일한 스타일로 생성할 수 있도록 별도의 GPT 링크를 공유해 드립니다.

사용 문의는 AX 팀 gcejshim@gccorp.com 으로 연락해 주세요.
헤드 이미지 / 섹션 일러스트 GPT 링크를 공유해 드리며, 동일한 스타일로 이미지를 생성하실 수 있습니다.

상단 헤드 이미지

카드 상단 대표 이미지 — 주제와 핵심 메시지를 입력하면 생성됩니다.

  1. 공유받은 GPT 링크로 접속합니다.
  2. 카드 제목과 주요 내용을 입력합니다.
  3. 생성된 이미지를 우클릭 → 이미지 복사합니다.

섹션 일러스트

각 본문 섹션 이미지 — 섹션 본문을 입력하면 어울리는 일러스트를 생성합니다.

  1. 공유받은 GPT 링크로 접속합니다.
  2. 해당 섹션 본문 내용을 붙여넣습니다.
  3. 생성된 이미지를 우클릭 → 이미지 복사합니다.
ChatGPT 무료 계정은 하루 이미지 생성 횟수가 제한됩니다. 한도 초과 시 STEP 3-B (Google Gemini Gems)를 이용하세요.
B

이미지 생성 대체 방법 ChatGPT 한도 초과 시

Google Gemini Gems 헤드 이미지 · 섹션 일러스트 공통

ChatGPT 이미지 생성 한도가 소진된 경우 Google Gemini Gems를 통해 동일한 스타일의 이미지를 생성할 수 있습니다.

사용 문의는 AX 팀 gcejshim@gccorp.com 으로 연락해 주세요.
Gems 링크를 공유해 드리니 접속해서 사용하실 수 있습니다.
  1. 공유받은 Gems 링크로 접속합니다.
  2. 생성할 이미지의 내용(제목 또는 섹션 본문)을 입력합니다.
  3. 이미지 스타일은 기본값을 유지하세요 (카드뉴스 스타일로 사전 설정됨).
  4. 생성된 이미지를 다운로드하거나 복사합니다.
4

생성한 이미지를 편집기에 적용

상단 헤드 이미지 적용

  1. 생성된 이미지를 Ctrl+C로 복사합니다.
  2. 편집기 상단 헤드 이미지 영역을 클릭합니다.
  3. Ctrl+V로 붙여넣거나, 이미지를 영역으로 드래그 앤 드롭합니다.

섹션 일러스트 적용

  1. 생성된 이미지를 Ctrl+C로 복사합니다.
  2. 편집기에서 교체할 섹션의 이미지 영역을 클릭합니다.
  3. Ctrl+V로 붙여넣거나 드래그 앤 드롭합니다.
  4. 미리보기에서 이미지가 정상 반영되었는지 확인합니다.
이미지 붙여넣기(Ctrl+V)는 Chrome / Edge에서 정상 동작합니다. Safari에서는 드래그 앤 드롭을 사용하세요.
이미지 삽입 영역 · 미리보기 반영
5

최종 저장 및 전달

상단 저장 버튼

HTML 파일로 저장

  1. 편집기 하단 [HTML 저장] 버튼을 클릭합니다.
  2. 저장할 파일명을 입력합니다. (예: card07_수정본.html)
  3. 저장 폴더를 선택하면 HTML 파일이 저장됩니다.
저장된 HTML 파일을 다시 브라우저에서 열면 편집을 이어서 할 수 있습니다.

이미지(JPG)로 저장

  1. 편집기 하단 [이미지 저장] 버튼을 클릭합니다.
  2. HTML 저장 시 선택한 폴더에 동일한 이름으로 JPG 파일이 저장됩니다.
화면 표시 해상도의 3배 크기로 저장되어 모바일 화면에서도 선명하게 표시됩니다. 카카오채널, 사내 게시물 등에 바로 첨부할 수 있습니다.

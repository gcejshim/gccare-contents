      뉴스레터 이미지 만드는 방법

      1. 호수를 입력해요. 년월과 파일명이 자동으로 정해져요. (15호 = 202610)
      2. 이미지 목록에서 블록 종류를 골라 [+ 추가]해요. 이미지 한 장이 블록 하나예요.
      3. 콘텐츠 번호와 이미지 번호를 기획안대로 맞춰요. 파일명: 202610_contents01_p01.png (PC) · _m01.png (모바일)
      4. 왼쪽 내용을 기획안대로 고쳐요. 오른쪽에서 PC·모바일이 같이 바뀌어요.
      5. 자동 점검에 주황색 경고가 없는지 확인해요. [메일 크기로 보기]로 실제 메일에서 보이는 크기도 확인해요.
      6. [이 이미지 저장]을 누르면 PC 2배(1800px)·모바일 3배(1050px) 이미지가 다운로드 폴더에 저장돼요. [전체 저장]은 목록 전체를 한 번에 저장해요. 크롬이 "여러 파일 다운로드"를 물으면 허용해 주세요.
      7. 저장 형식은 기본 PNG예요. 사진·화면 캡처가 큰 이미지만 JPG로 바꿔요. PNG가 1MB를 넘으면 자동 점검 아래에 [JPG로 저장] 버튼이 나와요.
      8. 나중에 고치려면 [편집 원본 저장] (.json) → [편집 원본 열기]

      작업 내용은 이 브라우저에 자동저장돼요. 처음이라면 [예시: 블록 10종]을 눌러 보고 고쳐 보는 게 가장 빨라요.

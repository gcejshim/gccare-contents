# 완성된 이미지를 우리 스타일로 바꾸기

다른 팀 · 다른 회사가 이미 완성한 콘텐츠 이미지(슬라이드형 PNG · 캡처 등)를 받아 AX Studio · Newsletter 블록으로 다시 만든다. (2026-11-13 사용자 확정, 16호 걸어봐 이미지로 정함)

## 원칙

1. **최대한 보이는 대로** — 배치 · 순서 · 카드 수 · 위 배지 위치 · 띠(헤더 색 영역) · 장식(발자국 등 단순 도형)까지 원본 그대로. 제목 줄 tag로 옮기거나 빼지 않는다.
2. **색 · 글꼴은 우리 것** — 글꼴 Pretendard, 색은 편집기 토큰(아래)에서 원본과 가장 가까운 것. 원본이 그린이면 그린 토큰, 블루면 블루 토큰.
3. **편집 가능하게** — 화면에 보이는 글자 · 숫자 · 색은 전부 편집기에서 고칠 수 있게(아래 '편집'). 배경(띠 · 바탕)과 장식 색까지.
4. **우리 템플릿을 기본으로, 없는 요소는 직접** — 맞는 템플릿(`type`)이 있으면 그것, 일부만 맞으면 `html` 블록에서 그 템플릿의 모양을 따라 하고 없는 요소(원형 그래프 · 작은 막대 · 점 · 장식)는 같은 톤으로 직접 그린다. 이걸 사용자에게 묻지 않는다.
5. **넓은 면적은 색 하나 + 자동 흰빛** (2026-11-13 사용자: 원톤은 부담, 두 브랜드 색을 잇는 그라데이션은 안 예쁨) — 띠 · 바탕 · 큰 판은 색 하나(`data-color`, 편집기에서 고름) 위에 흰빛을 얹어 오른쪽 아래로 갈수록 살짝 밝아지게 한다. 원본 걸어봐 띠도 한 그린이 빛 받듯 밝아지는 효과(#1f9d6b → #79d288).
   ```css
   .wk-band{position:absolute;overflow:hidden;…;background:var(--careGreen-600)}
   .wk-band:before{content:'';position:absolute;inset:0;background:linear-gradient(115deg,rgba(255,255,255,0) 35%,rgba(255,255,255,.38) 100%)}
   ```
   `<div class="wk-band" data-key="bgband" data-color="--careGreen-600" data-label="위 띠 색">` — 흰빛은 `:before`(장식 · 글자보다 아래). 두 색을 따로 고르게 하지 않는다. 막대 · 배지 · 아이콘 칸 · 버튼 같은 작은 요소는 단색. (design-system.md의 '그라데이션 장식 금지'보다 이 규칙이 우선)
6. **원본 한 장 = 블록 하나** (PC `html` · 모바일 `htmlMo`). 모바일은 나란한 카드를 위아래로, 시상대처럼 나란함이 뜻인 것은 유지.

## 그릴 수 있는 것 / 없는 것

| 원본 요소 | 처리 |
|---|---|
| 글자 · 숫자 · 카드 · 배지 · 그래프(원형 · 막대 · 점) · 아이콘 · 단순 장식 | HTML로 다시 그림 (아이콘은 Lucide `data-icon`) |
| 앱 · 관리자 화면 중 **글자 · UI 위주**(순위 목록 · 알림 · 말풍선 · 알림톡) | HTML로 다시 그림 → 글자까지 고칠 수 있음 |
| 앱 화면 중 **일러스트 · 사진 중심**(캐릭터 · 지도 그림 · 배경 사진) | 다시 그리지 않음. 앱 화면 2~4개 → `steps`, 화면 1장 → `hero`에 운영자가 캡처를 넣음. `html` 안에 섞여 있으면 그 자리를 비우고 "이 캡처는 편집기에서 넣어 주세요"라고 알림 |
| AI 이미지로 앱 화면 대신 그리기 | 하지 않음 (실제 서비스 화면과 달라짐) |

먼저 원본 한 장을 위 표대로 나눈 목록과 읽은 글자 · 숫자를 보여 주고 확인받은 뒤 만든다.

## 편집 (html 블록)

- 글자: `data-key` + `data-edit="text"` + `data-label`
- 막대 · 점 · 띠 · 바탕 · 장식: `data-key` + `data-color="--토큰"` + `data-label` (같은 색 묶음은 같은 key)
- 숫자에 따라 모양이 바뀌는 것(원형 그래프 %): `data.nums`에 값(`{"rate":"63.1"}`), HTML에 `{{#rate}}`, CSS에서 `var(--rate)` (예: `stroke-dasharray:calc(var(--rate) * 2.827px) 400px`, r=45 원)
- SVG 선 색처럼 `data-color`(배경색)로 안 되는 색: `data.colors`에 `{"ring":"--careGreen-500"}`, CSS에서 `stroke:var(--ring)` → 편집기 색 칸에서 고름

## 편집기에서 깨지는 것 (꼭 지키기)

- **클래스 이름은 `wk-` 같은 접두어**를 붙인다. 편집기 클래스(`ch` · `ic` · `bd` · `on` · `bg` 등)와 겹치면 여백 · 정렬이 바뀐다. 템플릿 모양을 일부러 쓸 때만 템플릿 클래스 그대로.
- **직접 그린 막대는 편집기가 폭을 칸의 60%로 줄인다** → 원본처럼 꽉 차게 하려면 `.wk-bars span{flex:1 1 0 !important;width:auto !important;max-width:none !important}`. 점 · 원처럼 크기가 정해진 것은 `flex:none !important`(안 그러면 타원으로 눌림).
- **막대가 있는 블록에서 자식이 하나뿐인 글자 줄은 축 글자로 오인돼 작아진다**(제목이 14px로) → 제목 줄에 빈 `<small></small>`를 하나 더 둔다.
- **색 토큰은 이 목록만**: careBlue 10·50·100·200·300·400·500·600·700·800·900, careGreen 10·50·100·300·500·600·700, careRed 50~600, careOrange 50~600, careYellow 100·200·300·500, coolNeutral 50·100·200·300·400·500·600, neutral 0·100·900. (careGreen-400 · 800은 이미지에서 색이 안 나옴)
- 바탕까지 직접 그리면 블록 `bg`는 `none`, 바깥 div에 바탕색 + 안 여백(PC `44px 40px 36px` · 모바일 `28px 16px 24px`).
- 큰 카드 3개 나란히(PC)는 `grid-template-columns:repeat(3,minmax(0,1fr))` — `1fr`만 쓰면 내용 길이에 따라 카드 폭이 달라진다. 카드 제목은 `white-space:nowrap`.

## 디자인 점검 (주기 전에 원본과 나란히 보고)

- 막대 · 그래프가 원본만큼 채워졌나(얇거나 작아지지 않았나), 원형 그래프 크기, 점 크기
- 카드 폭이 같나, 제목이 이상하게 줄바꿈되지 않았나
- 원본에 있는 장식 · 띠 · 배지가 다 있나
- 모바일에서 넘치거나 겹치는 글자가 없나

## 예시 (16호 서브 02-1 걸어봐 참여결과)

그린 띠(`--careGreen-600` + 흰빛, 발자국 장식 4개 `--careGreen-300` 투명도 .55) 위에 배지 · 흰 제목, 아래 바탕 `--coolNeutral-50`. 흰 카드 3개(모서리 20 · 그림자): ① 원형 그래프 63.1% + 210명 ② 7,887보 + 막대 10개(9번째만 `--careGreen-500`, 나머지 `--careGreen-50`) ③ 154명 + 점 10개(7개 `--careGreen-500`). 카드 아이콘은 `--careGreen-10` 둥근 네모 안 Lucide, 큰 숫자 `--careGreen-600`, 설명 `--coolNeutral-600`, 아래 집계 기준 문구.

# GC케어 뉴스레터 썸네일 — 그릴 것 키워드만

콘텐츠 내용을 보고 AX Studio · Newsletter › **뉴스레터 썸네일** 메뉴 「무엇을 그릴까요?」에 넣을 **키워드만** 준다 (2026-10-20 사용자 지정).

- 타이틀 · 배경 · 참고 이미지 · 칩은 **정하지도 추천하지도 않는다.** 사용자가 도구에서 고른다.
- 결과 JSON에는 키워드(`gen.desc`)만 있다. 붙여 넣으면 도구의 「무엇을 그릴까요?」 칸만 바뀌고 나머지는 그대로다.
- 미리보기는 없다(그림은 도구가 그림).
- 사용자가 "타이틀도" 하면 그때만 `title`을 더한다(아래).

## 진행 순서

1. 기획안에서 **호수**(예: 15호)와 콘텐츠 목록(01 메인, 02 · 03 서브)을 찾는다. 호수가 없으면 물어본다. 참고: 14호=2026년 9월, 15호=2026년 10월, 이후 한 달에 한 호씩.
2. 콘텐츠마다 **「썸네일 01 JSON」 아티팩트 하나**(코드 · 언어 `json`, 안에는 JSON만)를 준다.
3. 넣는 방법 한 줄: "[복사] → AX Studio · Newsletter **아무 화면에서 Ctrl+V** 하면 썸네일 메뉴 「무엇을 그릴까요?」에 들어가요. 타이틀 · 배경 · 참고 이미지를 고르고 [✦ 이미지 만들기]를 누르세요."

## JSON 형식 (이것만)

```json
{"kind":"nl-thumb","v":1,"issue":15,"no":"01","gen":{"desc":"공시 책자, 체크리스트 클립보드, 막대그래프 카드"}}
```

`kind` 항상 `"nl-thumb"`, `v` 항상 1, `issue` 호수 숫자, `no` "01" · "02" · "03".

## 키워드 (`gen.desc`) 정하는 법

- **어디서 내용을 읽나**: 사용자가 올린 기획안에서 그 콘텐츠(01 · 02 · 03)의 **본문 쪽**(콘텐츠 이미지 기획 · 표 · 설명 · 수치)을 읽는다. 썸네일 예시 쪽의 제목 한 줄만 보고 정하지 않는다. 같은 대화에서 콘텐츠 이미지를 이미 만들었으면 그 내용도 참고한다.
- **콘텐츠 내용에 맞는 구체적인 물건 이름**. 개념어(안전 · 보안 · 알림)를 쓰면 안전모 · 자물쇠 · 종처럼 그대로 물건이 되므로, 주제를 보여 줄 물건을 직접 고른다.
- **중심 물건 1개 + 보조 1~2개**, 가장 큰 것 먼저. 병원 · 진료 도구(청진기 · 주사기)보다 기업 건강관리 물건(앱 화면 휴대폰 · 대시보드 · 리포트 · 달력 · 체크리스트)을 우선.
- **물건 이름만** 쓴다. 스타일 · 색 · 구도 말은 쓰지 않는다(그림체는 도구가 맞춤).
- 그림 안에 글자가 필요하면 따옴표로 쓴다(예: 책자 제목 "안전보건 공시"). 따옴표 글자만 그림에 들어간다.
- 인물이 필요하면 "3D 캐릭터 직원이 노트북 앞에서 고민"처럼 장면으로 쓴다. 실제 인터뷰 · 고객사 인물은 그리지 않고 `desc`를 빈 문자열로 두고 "실제 사진을 붙여 넣어 주세요"라고 안내한다.
- '안전 · 안전보건'은 공사장이 아니라 직장인 건강관리로 본다(안전모 · 공사 현장 X).
- 기획안에 썸네일 **예시 그림**이 있으면 그릴 물건을 정하는 참고로만 쓴다. 따라 그리거나 HTML · 스크립트로 다시 만들지 않는다.

## 타이틀 (사용자가 "타이틀도"라고 할 때만)

`"title"`을 JSON에 더한다. 기획안 문구 그대로, `\n`으로 3줄 이내(한 줄 한글 약 9자), 강조는 `[대괄호]` 한 곳 2~6자. 조사 · 어미 앞에서 끊지 않는다.

## 예시

```json
{"kind":"nl-thumb","v":1,"issue":14,"no":"01","gen":{"desc":"건강검진 결과지를 든 손, 결과 리포트 앱 화면 휴대폰"}}
```

```json
{"kind":"nl-thumb","v":1,"issue":14,"no":"02","gen":{"desc":"걸음 수 앱 휴대폰, 흰 · 파랑 운동화"}}
```

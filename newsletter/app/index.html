뉴스레터 만들기

GC케어 뉴스레터 만들기 개발본
작업은 이 브라우저에 자동저장돼요

콘텐츠마다 썸네일 · PC · 모바일 이미지를 만들면 저장할 때 자동으로 체크돼요. 다 만들면 [호 전체 저장]으로 작업 파일을 보관해 두세요.

호 정보

콘텐츠 한 호 = 콘텐츠 2~3개

저장 기록 이 브라우저에서 저장한 파일

    작업 순서

    1. 기획안을 받아 콘텐츠 제목과 메모를 적어요.
    2. 뉴스레터 썸네일을 콘텐츠마다 1장씩 만들어요.
    3. 콘텐츠 이미지 생성에서 블록을 골라 PC · 모바일 이미지를 만들어요.
      어떤 블록이 맞을지 모르겠으면 에셋 › 샘플 모아보기에서 10~14호를 참고해요.
    4. 배경 · 일러스트가 필요하면 에셋 › AI로 그리기에서 프롬프트를 만들어 ChatGPT에 붙여 넣어요.
    5. 저장 기록에 1MB 초과 표시가 없는지 확인하고 납품해요.
    6. [호 전체 저장]으로 작업 파일을 보관해요.

    PDF는 준비 중이에요

    15호 PC · 모바일 블록을 만들면서 그 블록을 그대로 재사용해 PDF 템플릿을 만들 예정이에요.

    • 규격: A4 세로 (900 × 1273) · 게시판 업로드 · 화면 열람용
    • 방향: 한 페이지 한 메시지, 큰 숫자 · 도식, 본문 최소화 (토스 콘텐츠 벤치마킹)
    • 내보내기: 브라우저 인쇄 → PDF (글자가 실제 텍스트로 남음)

    에셋

    이미지는 각 도구에 바로 붙여넣기(Ctrl+V)하거나 끌어다 놓으면 돼요. 여기서는 지난 호 샘플을 참고하고, 로고 · 아이콘 · 컬러를 확인하고, AI 이미지 프롬프트를 만들어요.

    무엇을 그릴까요?

    ⚠️ 이미지 안에는 글자를 넣지 않아요. 글자는 썸네일 · 콘텐츠 도구에서 넣어요. 인물 실사 사진은 회사 보유 사진만 써요(AI 실사 인물 X).

    ChatGPT에 붙여 넣을 프롬프트ChatGPT 열기

    만든 이미지는 ChatGPT에서 복사하거나 저장한 뒤, 썸네일 · 콘텐츠 도구에 Ctrl+V로 넣어요. 썸네일은 뉴스레터 썸네일 › 이미지 만들기에서 배경 · 레이아웃에 맞춘 프롬프트를 바로 짜 주고, 빠른 시안도 만들 수 있어요.

    로고

    아이콘 Lucide · 콘텐츠 이미지 블록에서 고를 수 있는 아이콘

    뉴스레터 컬러 13·14호 기준 → 디자인 시스템 토큰 (누르면 색상값 복사)

    가이드

    뉴스레터 산출물 규격과 디자인 원칙이에요. 바꾸지 말아야 할 기준이 모여 있어요.

    산출물 규격

    산출물작업 크기저장비고
    PC 이미지폭 9002배 (1800px)메일에서 약 660px로 줄어 보임 → 본문 최소 18, 가장 작은 글자 14, 선 1.5px 이상
    모바일 이미지폭 3503배 (1050px)타이틀 16·18 / 본문 14·16
    썸네일399 × 2313배 (1197 × 693)타이틀 26 (길면 22)
    PDFA4 세로 900 × 1273인쇄 → PDF게시판 · 화면 열람용
    파일 크기1MB 이하. 넘으면 사진이 많은 이미지만 JPG(품질 90)로 저장. 이미지 크기는 줄이지 않음(2·3배 의미가 사라짐)

    디자인 원칙 바꾸지 말 것

    관점앱 화면이 아니라 B2B(HR · 보건 담당자) 정보 콘텐츠 → 편집 디자인 · 인포그래픽. 디자인 시스템은 컬러 · 타이포 토큰만 사용
    컬러블루톤 기반 + 그린(careGreen)은 포인트로만. 예외: 타이틀 #002540, 그린 배경 #20B977
    아이콘Lucide 라인 아이콘이 기본. 채움은 강조할 때만
    이미지AI 이미지에는 글자를 넣지 않음(글자는 항상 HTML로). 인물 사진은 회사 보유 사진만
    작업 방식초안을 넓게 먼저 잡고 점점 좁혀 감. 요청하지 않은 산출물은 늘리지 않음

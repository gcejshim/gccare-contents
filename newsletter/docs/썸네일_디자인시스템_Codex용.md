# 뉴스레터 썸네일 디자인 시스템

Oct 7, 2026 · @심은진

이 문서는 GC케어 뉴스레터 썸네일에 들어갈 **이미지를 만드는 작업자(Codex)를 위한 기준**이에요. 이미지에는 글자를 넣지 않고, 타이틀·로고·칩은 나중에 썸네일 도구가 올려요.

## 작업 지시

기업 건강관리 뉴스레터(독자: 기업 인사·보건 담당자) 썸네일의 오른쪽 이미지를 만들어요. 요청마다 아래 값을 받아요.

| 받는 값 | 예 |
| --- | --- |
| 썸네일 타이틀 (내용 참고용, 이미지에 쓰지 않음) | 걷기 챌린지, 더 오래 참여하고 더 쉽게 운영하려면? |
| 배경색 | 라이트 블루 #F0F8FF (아래 「컬러」 표) |
| 레이아웃 | 장면형 / 오브젝트형 / 사진형 |
| 스타일 | 3D / 실사 사물 / 실사 인물 |
| 그릴 것 (없을 수 있음) | 걷기 앱이 켜진 휴대폰, 운동화 |
| 참고 이미지 (없을 수 있음) | 14호 썸네일 |

**레이아웃별 결과물**

| 레이아웃 | 크기 | 배경 | 구도 |
| --- | --- | --- | --- |
| 장면형 | 1536 × 1024 PNG (3:2) | 배경색 단색에 가깝게 | 왼쪽 55%는 완전히 비움(타이틀 자리). 주제는 오른쪽 45%, 오른쪽 아래에 무게 |
| 오브젝트형 | 1024 × 1024 PNG | 투명 | 물건을 가운데 모으고 사방 여백 넉넉히, 바닥에 아주 옛은 그림자만. 배경색 위에서 또렷하게 보이는 색 |
| 사진형 | 1536 × 1024 PNG (3:2) | 가장자리 톤이 배경색과 이어지게 | 주제는 가운데\~오른쪽 |

**진행 순서**

1. 타이틀(또는 「그릴 것」)을 보고 주제를 대표하는 물건 **2\~3개**를 고르세요. 주인공 1개 + 곁들이는 물건 1\~2개.
2. 아래 「이미지 스타일」의 스타일·금지·인물 규칙에 맞춰 만드세요.
3. 참고 이미지가 있으면 **재질·조명·색·여백만** 참고하고, 물건과 구도는 이번 주제에 맞게 새로 그리세요. 참고 이미지를 고치는 작업이 아니에요.
4. 맨 아래 「저장 전 체크리스트」의 이미지 항목을 확인하고 넘겨 주세요. 고른 물건과 이유를 한 줄로 함께 알려 주세요.

**프롬프트 틀** (장면형·3D 예시, { } 자리를 바꿔 쓰세요)

```
뉴스레터 썸네일 배경 이미지를 만들어 줘.

[썸네일 타이틀 · 내용 참고용]
"{타이틀}"
→ 이미지 안에 글자로 쓰지 말고, 무엇을 그릴지 정하는 참고로만 써 줘.

[그릴 것]
{그릴 것 — 없으면: 타이틀을 대표하는 물건 2~3개를 골라 단순하게}
기업 건강관리(건강검진 · 사후관리 · 사내 건강관리)와 분명히 관련 있어야 해.
물건은 2~3개만. 주제와 상관없는 소품(화분, 컵, 장식, 떠다니는 아이콘 · 도형 등)은 넣지 말 것.

[구도]
- 가로 3:2 (1536×1024).
- 왼쪽 55%는 완전히 비워 둘 것(타이틀 글자 자리). 거의 단색인 {배경색}만.
- 주제는 오른쪽 45%에, 오른쪽 아래에 무게. 물건이 화면 밖으로 잘리지 않게.

[스타일]
- 매끈한 3D 제품 렌더. 실제 재질감(유리 · 무광 플라스틱 · 패브릭), 부드러운 스튜디오 조명과 은은한 반사광, 바닥에 옛은 그림자. 장난감 · 클레이 느낌은 피할 것.
- 색: 블루 톤(#2F74EB, #1D55C4, #D6EAFF) 위주, 초록(#0AC262)은 작은 포인트로만.

[절대 금지]
- 글자, 숫자, 영어, 한글, 로고, 라벨을 이미지 어디에도 넣지 말 것.
- 휴대폰 · 모니터 · 기기 화면에도 숫자 대신 아이콘이나 그래프만.
- 워터마크, 테두리 금지.

[용도]
GC케어 기업 건강관리 뉴스레터 썸네일. 독자는 기업 인사 · 보건 담당자.
```

## 컬러

배경은 아래 6가지 중에서 고르고, 타이틀·강조 단어·로고 색은 배경에 따라 자동으로 정해져요. 기본은 라이트 블루예요.

| 배경 | 배경색 | 타이틀 | 강조 단어 | 로고 |
| --- | --- | --- | --- | --- |
| 라이트 블루 (기본) | careBlue/50 #F0F8FF | #002540 | careBlue/500 #2F74EB | 블루 |
| 화이트 | coolNeutral/50 #F7F7FB | #002540 | careBlue/500 #2F74EB | 블루 |
| 네이비 | careBlue/900 #031552 | 흰색 #FFFFFF | careGreen/400 #2BCF75 | 흰색 |
| 블루 | careBlue/600 #1D55C4 | 흰색 #FFFFFF | careBlue/100 #D6EAFF | 흰색 |
| 라이트 그린 | careGreen/10 #F5FFF8 | #002540 | careGreen/600 #009C50 | 블루 |
| 그린 | #20B977 | 흰색 #FFFFFF | #002540 | 남색 |

- **타이틀 색 #002540**은 썸네일에만 쓰는 색이에요. 콘텐츠 이미지 글자는 #111111을 써요.
- **그린 #20B977**은 디자인 시스템 밖의 뉴스레터 전용 색이에요. 글자 대비 안내는 일부러 생략해요.
- \*\*색 찍기(스포이트)\*\*는 이미지 배경과 색을 딱 맞춰야 할 때만 써요. 어두운 색이면 흰 글자, 밝은 색이면 #002540으로 자동 전환돼요.
- 이미지 색은 블루 톤(#2F74EB, #1D55C4, #D6EAFF) 위주, 초록(#0AC262)은 작은 포인트로만 써요.

## 타이포

타이틀은 **Pretendard Bold 26 / 줄 높이 32** 한 가지만 써요. 엔터로 나눈 줄 그대로 보이고, 3줄 이내로 써요. 길면 글자를 줄이지 말고 문장을 줄여요.

- 굵기 700(Bold), 자간 -0.104 px, 단어 중간에서 줄이 끊기지 않게 해요.
- 강조할 단어는 \*\*\[대괄호\]\*\*로 감싸요. 예: 검진 결과가 \[나왔습니다.\] → 강조색으로 바뀌어요.
- 한 글자만 남는 줄은 앞 줄과 합쳐요.
- 줄 폭은 343 px(399 − 여백 28×2)을 넘지 않아야 해요. 넘치면 저장 이미지에서도 잘려요.

## 로고·칩

로고는 왼쪽 위, 타이틀은 그 아래, 칩은 맨 아래에 놓여요. 칩은 꼭 필요할 때만 켜요.

| 요소 | 규칙 |
| --- | --- |
| 로고 | 14호 단색 **영문** GC Care 로고, 78 × 19 px. 밝은 배경은 블루, 어두운 배경은 흰색 (콘텐츠 이미지는 한글 로고라 다름) |
| 칩 개수 | 최대 3개 |
| 칩 문구 | 7자 이내 — 예: 결과 확인, 사후관리, 건강관리 계획 |
| 칩 모양 | 높이 28 px, 둥근 흰 바탕, 글자 12 px SemiBold #2A2A2A, 사이 간격 6 px |
| 칩 아이콘 | Lucide 라인 아이콘 14 px (사람, 상담, 걷기, 일정 등 22종 중 선택) |

칩을 켜면 타이틀은 3줄까지만 써요. 4줄이면 글자와 칩이 붙어 보여요.

## 레이아웃 3종

어떤 레이아웃이든 왼쪽은 글자 자리, 오른쪽은 이미지 자리예요. 이미지 종류에 따라 골라요.

| 레이아웃 | 이미지 | 자리 | 배경색 | 이럴 때 |
| --- | --- | --- | --- | --- |
| 장면형 (기본) | 배경까지 있는 가로 3:2 이미지 | 전체를 채움, 왼쪽 55%는 비어 있어야 함 | 이미지 배경 그대로, 글자색은 이미지 밝기로 자동 | 3D나 실사로 한 장면을 크게 보여 줄 때 |
| 오브젝트형 | 배경이 투명한 PNG (정사각형) | 오른쪽 58% | 고른 배경색 | 물건 하나를 또렷하게 올릴 때 |
| 사진형 | 일반 사진 | 오른쪽 52%, 왼쪽 경계는 배경색으로 흐릿하게 | 고른 배경색 | 실제 인터뷰·고객사 사진 |

장면형에서 배경색을 고르면 사진형으로 바뀌어요. 단, \[바로 만들기\]로 배경색에 맞춰 만든 장면은 고른 색을 유지하고 왼쪽을 배경색으로 이어 줘요.

## 이미지 스타일

이미지는 주제를 대표하는 물건 **2\~3개**만 그리고, 글자·숫자는 어디에도 넣지 않아요.

| 스타일 | 느낌 | 참고 |
| --- | --- | --- |
| 3D | 매끈한 3D 제품 렌더. 유리·무광 플라스틱·패브릭 같은 실제 재질, 부드러운 조명과 은은한 반사광. 장난감·클레이 느낌은 피함 | 14호 걷기 챌린지(휴대폰 + 운동화) |
| 실사 사물 | 사람 없는 제품 사진. 자연광, 얕은 심도 | 12호 커피 썸네일 |
| 실사 인물 | 검진센터·상담·사내 건강관리 장면의 가상 인물 사진. 자연광, 따뜻한 분위기 | — |

**구성**

- 물건은 2\~3개. 주제와 상관없는 소품(화분, 컵, 장식, 떠다니는 아이콘·도형)은 넣지 않아요.
- 물건이 화면 밖으로 잘리지 않게, 오른쪽 아래에 무게를 두어요.
- 기업 건강관리(건강검진·사후관리·사내 건강관리)와 분명히 관련 있어야 해요.

**금지**

- 글자, 숫자, 영어, 한글, 로고, 라벨. 휴대폰·모니터 화면에도 숫자 대신 아이콘이나 그래프만.
- 워터마크, 테두리.

**인물**

- AI 인물은 가상의 한국인, 기본 사무직 차림. 실제 인터뷰·고객사 인물은 실제 사진을 써요.
- 3D 인물은 카드뉴스 편집기 캐릭터 얼굴(여자·남자)을 써요. 의사는 같은 얼굴로 50대(흰머리·흰 가운), 성별이 없으면 남자.
- 의상: 여자는 배경색 계열(베이지·갈색 제외), 남자는 블루 톤.

## 저장 전 체크리스트

자동 점검에 주황색 경고가 없으면 저장해도 돼요. 아래는 자동 점검이 보는 항목이에요.

- [ ] 타이틀이 3줄 이내이고, 줄이 밖으로 넘치지 않아요.
- [ ] 한 글자만 남은 줄이 없어요.
- [ ] 강조 대괄호 \[ \]의 짝이 맞아요.
- [ ] 글자·배경 대비가 3 : 1 이상이에요 (웹 접근성 기준 WCAG 2.1, 큰 글씨). 강조 단어도 같아요.
- [ ] 칩을 켰다면 문구가 7자 이내예요.
- [ ] 이미지에 글자·숫자가 없고, 물건은 2\~3개예요.
- [ ] 오브젝트형이라면 배경이 투명한 PNG예요.
- [ ] 파일명의 호수·콘텐츠 번호가 맞아요.
- [ ] &#91;편집 원본 저장\]도 눌러 두었어요.

# 이미지 프롬프트 구성

AX Studio · Newsletter가 AI 이미지(썸네일 배경 · 리드마그넷 표지 그림)를 만들 때 쓰는 프롬프트예요. 아래 「실제 프롬프트」는 15호 작업에서 도구가 만든 것을 그대로 꺼낸 거예요 (2026-10-22 기준).

## 한 줄 요약

사람은 **「그릴 것」 한 줄**만 적어요. 나머지(배경색 · 배치 · 위계 · 그림체 · 금지 사항)는 도구가 고른 값에 맞춰 규칙을 자동으로 붙여요. 규칙은 지난 호 썸네일 16장을 분석해 만들었고, 생성이 잘못될 때마다 원인을 하나씩 더해 왔어요.

## 구성

| 덩어리 | 들어가는 것 | 왜 |
|---|---|---|
| 맨 앞 · 맨 끝 규칙 | 글자 · 숫자 · 로고 금지, 물건 최대 3개, 왼쪽 비우기 | 가장 자주 어기는 규칙이라 두 번 말함. 제목은 그림이 아니라 HTML로 얹음 |
| 주제 | 타이틀(참고용) + 그릴 것 | 그릴 것을 비우면 타이틀 키워드(검진 · 스트레스 · 공시 등 10가지)에 맞는 물건 목록에서 고름 |
| 회사 맥락 | 독자 = 기업 인사 · 보건 담당자, 병원 아님, '안전보건' = 직장인 건강관리 | 안전모 · 공사장 · 청진기가 자꾸 나와서 |
| 구성 · 위계 | 중심 1 + 보조 최대 2, 같은 시점 · 조명, 삼각 구도, 장식 금지 | 물건이 따로 떠 있거나 너무 많던 문제 |
| 배경과 색 | 고른 배경색 HEX 그대로, 배경 밝기에 맞는 물건 색 | 그림과 표지 · 썸네일이 경계 없이 이어지게 |
| 스타일 | 고른 그림체(13종)의 화풍 설명. 색은 그림체가 아니라 배경색을 따름 | 그림체 샘플 색(예: 오렌지)이 따라 나오던 문제 |
| 구도 | 썸네일: 가로 3:2, 왼쪽 55~60% 비움 / 리드마그넷: 세로 2:3, 위 45% · 왼쪽 38% 비움 | 제목 · 로고 자리 |
| 참고 이미지 (썸네일) | 지난 호 배경 중 지금 배경색 · 유형에 맞는 것 + 그 설명 | 배치 · 색 분위기만 따르고 물건은 새로 |

## 어디서 보나요

- **리드마그넷**: ③ 표지 그림 아래 「프롬프트 보기」
- **AI로 그리기 메뉴**: 오른쪽 프롬프트 칸 (복사 · ChatGPT 열기)
- **뉴스레터 썸네일**: 화면에는 숨김(10/15부터 [✦ 이미지 만들기]로 바로 보냄). 이 문서에서 확인

- GC케어 기업 건강관리 뉴스레터용. 독자는 기업 인사 · 보건 담당자. 병원 · 진료실이 아니라 회사의 건강관리 업무(플랫폼 · 데이터 · 리포트 · 담당자 업무)의 느낌으로.

[구성]
- 중심 대상 1개 + 보조 대상 최대 2개(꼭 필요할 때만). 보조 대상은 중심보다 작게, 앞이나 옆에 살짝 겹쳐 한 덩어리로 놓는다. 물건이 적고 여백이 넉넉할수록 좋다.
- 보조 대상을 중심 대상 표면에 아이콘 · 그림으로 그려 넣지 않는다. 각각 입체 물건으로 세운다.
- 모든 물건은 하나의 장면으로 그린다: 같은 카메라 각도(중심 물건을 살짝 위에서 내려다보는 3/4 시점), 같은 원근, 같은 조명 방향.
- 보조 물건은 중심 물건을 기준으로 크기를 맞춘다(중심의 약 30~50%). 중심 물건 바로 옆 · 앞에 붙여 겹치듯 한 덩어리로 놓고, 따로 떠 있거나 멀리 떨어뜨리지 않는다.
- 모든 물건이 같은 바닥면 위에 놓이고, 같은 방향으로 부드러운 바닥 그림자가 생긴다.
- 위계: 중심 물건이 가장 크고 앞쪽에서 또렷하게 강조된다(물건 무리의 약 60%). 보조 물건은 작고 살짝 뒤 · 옆에 두어 채도와 대비를 한 단계 낮춘다.
- 구도: 물건 무리는 오른쪽 영역 안에서 안정적인 삼각형을 이룬다. 중심 물건이 꼭짓점(가장 높고 큰 쪽), 보조 물건 둘이 아래 양쪽 밑변. 보조 물건이 하나면 중심과 대각선으로 놓는다.
- 주제와 직접 관계없는 장식(메가폰 · 확성기 · 화살표 · 반짝이 · 말풍선 등)은 넣지 않는다.
- 안전모 · 헬멧 · 안전조끼 · 공사 현장 · 경고 표지 · 소화기 같은 산업안전 물건과 자물쇠 · 열쇠 같은 보안 상징은 넣지 않는다. 보호 · 예방은 체크 방패로 표현해도 좋다.

[배경과 색]

- 물건 색은 남색 배경에 어울리는 밝은 톤으로: 흰색 · 연한 하늘색 · 밝은 파랑을 중심으로 3~4단계 명도를 섞고, 초록과 노랑은 작은 포인트로. 배경 위에서 또렷하게 보이도록 밝은 반광 재질.
- 어두운 배경이므로 대상은 밝은 재질로, 가장자리 빛은 절제해서 윤곽만 살린다.

[스타일]
- 사진처럼 보이지 않는 세련된 3D 일러스트. 둥글고 매끈한 형태, 매트에 살짝 유광이 섞인 재질, 부드럽고 고른 조명, 은은한 그림자.
- 단순하고 정돈된 형태, 현대적이고 세련된 느낌. 실제 사진 · 실물 같은 질감, 장난감 · 클립아트 · 오래된 아이콘 같은 느낌은 피한다.
- 색은 2~3가지 차분한 색 + 포인트 1색. 과한 광택 · 반짝임 · 과한 채도 · 뽀얗게 날아간 과노출은 피한다.

[구도]
- 가로 3:2 (1536×1024). 썸네일로 쓸 때 위아래가 조금 잘린다.
- 왼쪽 55~60%는 물건 · 소품 · 그림자 없이 배경색만 둔다 (타이틀 · 로고 자리).
- 물건은 오른쪽 40~45%, 세로 가운데~아래쪽에 모은다. 물건 둘레(위 · 아래 · 오른쪽)에 배경 여백을 넉넉히 두고, 화면 가장자리에서 잘리지 않게 그린다.
- 물건 아래에는 바닥에 닿는 부드럽고 은은한 그림자를 자연스럽게 넣는다. 배경색보다 살짝 어두운 같은 계열 톤으로, 진한 검은 그림자는 쓰지 않는다.

- 주제 이해에 필요하지 않은 수치나 사실은 지어내지 않는다.

[참고 이미지]
- 첨부한 참고 이미지(우리 뉴스레터 지난 호 썸네일 배경)에서는 배치 · 구도 · 색 분위기만 참고한다. 재질 · 조명은 위 [스타일]을 따른다(지난 호보다 더 세련되게). 참고 이미지에 떠 있는 카드 · 배지 · 아이콘이 있어도 따라 그리지 않는다.

- 참고 이미지의 물건 · 인물 · 글자는 따라 그리지 않는다. 대상은 이번 주제로 새로 정한다.

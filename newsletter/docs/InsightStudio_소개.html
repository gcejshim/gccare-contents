뉴스레터, 보건관리 자료실 같은 회사 인사이트 콘텐츠를 운영자가 직접 제작할 수 있는 공간입니다.

2026년 10월 15일 기준v1.0

목적

기획안만 있으면 같은 품질의 콘텐츠를 바로

GC케어 홈페이지의 뉴스레터와 보건관리 자료실은 HR·보건 담당자에게 건강 데이터와 트렌드를 전하는 회사의 인사이트 채널입니다. Insight Studio는 IPR팀 기획안을 받아 썸네일과 콘텐츠 이미지(PC·모바일)를 회사 디자인 기준에 맞게 만들고, 규격과 파일명까지 맞춰 저장하는 데까지를 한곳에서 처리합니다.

운영자가 직접 제작

템플릿에 내용만 넣으면 PC·모바일 이미지가 함께 완성됩니다.

일정한 품질

DS 컬러·타이포, 지난 호 원본 디자인을 템플릿에 담아 호마다 톤이 같습니다.

빠른 제작

Claude 스킬이 기획안을 작업 내용으로 바꿔 주고, 호 전체를 한 번에 저장합니다.

작업 흐름

  1. 기획안IPR팀 기획안(PPT·PDF·문서). 차트 수치도 여기에 있음
  2. Claude 스킬기획안 → 썸네일·콘텐츠 이미지 작업 내용(JSON)
  3. AX Studio · NewsletterCtrl+V로 붙여넣고 글자·색·이미지 다듬기, 자동 점검
  4. 저장규격 배율·파일명 규칙대로 호 전체 이미지를 한 번에

파일 하나(HTML)로 동작하고 서버 설치가 필요 없습니다. 크롬·엣지에서 열면 되고, 인터넷이 없어도 씁니다(AI 이미지 생성만 인터넷 필요).

호수를 한 번 정하면 모든 메뉴에 같이 적용되고, 저장한 파일은 「이번 호」 체크리스트에 자동으로 표시됩니다.

만든 기능

썸네일 만들기

  • 타이틀 입력(강조는 [대괄호]), 배경 6종 + 스포이트로 직접 색 지정, 레이아웃 3종(장면형·오브젝트형·사진형)
  • 이미지는 끌어다 놓기·클릭·붙여넣기. 배경 밝기에 따라 글자색 자동
  • 자동 점검: 글자 대비(WCAG 큰 글씨 3:1 기준) 등 문제를 한 줄로 안내하고 해결법 제시
  • 콘텐츠 번호(01·02·03)를 바꾸면 한 호의 썸네일을 차례로 작업

콘텐츠 이미지 템플릿 21종

  • 8개 묶음: 표 · 막대 그래프 · 선·원 그래프 · 리스트·카드 · 인용·인터뷰 · 숫자·흐름 · 화면·사진 · 직접 만들기
  • 지난 10~14호 Figma 원본을 기준으로 재현(표·순위 막대·단계 흐름·큰 숫자·CTA 배너 등)
  • 차트는 이미지가 아닌 HTML로 그려 저장해도 선명. 색·축·기준선·강조 방식·변화량 배지 지정
  • 미리보기에서 글자·숫자를 바로 클릭해 수정, 글자 색 도구(블루·그린·빨강), 아이콘 93개
  • PC와 모바일을 함께 미리보기, 메일 크기(630px)로도 확인
  • 템플릿에 없는 형태는 Claude 스킬로 「직접 만든 블록」을 만들어 붙여넣기

AI로 그리기 10월 새 메뉴

  • 배경색·이미지 유형(3D 배경 포함·3D 오브젝트·실사·실사 오브젝트)·그릴 것을 고르면 프롬프트를 자동으로 만들어 바로 생성
  • 참고 이미지 19장(지난 호 썸네일 배경 + 보건관리 자료실)에서 지금 조건에 맞는 것을 추천해 함께 첨부 → 톤 유지
  • [AI 이미지 생성] 버튼 하나로 도구 안에서 바로 생성(외부 ChatGPT 작업 없음)
  • 인터뷰용 3D 얼굴 9개(20~50대, 사무직·현장직·의사·간호사)

호 단위 관리·저장

  • 상단 버튼은 호 전체: [불러오기 · 전체 파일 저장 · 전체 이미지 저장]
  • 전체 이미지 저장 한 번이면 썸네일 + 콘텐츠 이미지 PC·모바일이 폴더에 파일명 규칙대로 저장
  • 화면 아래 [이 이미지 저장]은 지금 보는 한 장. 작업 내용은 브라우저에 자동 저장

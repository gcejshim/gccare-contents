편집기 실행 시 소속 확인 팝업

편집기를 열면 AI 이미지 생성 기능을 쓰기 전에 회사 · 팀명 · 이름을 확인하는 팝업이 뜹니다. 회사를 선택하고, 팀명과 이름을 입력(또는 목록에서 선택)한 뒤 "확인"을 눌러야 편집기가 정상적으로 열립니다. 한 번 입력하면 다음부터는 자동으로 채워집니다.

타이틀 텍스트 입력/수정

  1. 화면 왼쪽 편집 패널에서 수정할 섹션의 소제목 또는 본문 텍스트를 클릭합니다.
  2. 내용을 직접 입력하면 오른쪽 미리보기에 실시간으로 반영됩니다.
  3. 줄바꿈은 Enter, 단락 구분은 빈 줄로 처리합니다.
수정 후 반드시 저장을 진행해야 변경사항이 유지됩니다. 브라우저를 닫으면 미저장 내용은 사라집니다.

API (OpenAI) 이미지 자동생성

GPT API로 헤더 · 본문 이미지를 자동 생성!
회사 공용키가 기본 적용되어 있어 별도 설정 없이 바로 사용할 수 있습니다. 카드 뱃지 선택 → 헤더 스타일 선택 → 헤더 이미지 생성 → 본문 캐릭터 선택 → 본문 자동생성까지 전체 흐름이 API로 자동 구현됩니다.
▲ 본문 섹션 이미지 슬롯 예시 — 캐릭터 선택 후 본문 자동생성으로 적용

이미지 생성 순서

API 키 등록 후 아래 순서대로 진행하면 헤더·본문 이미지를 자동 생성할 수 있습니다.

1
카드 뱃지 선택
편집기 상단 카드 뱃지 입력란에 뱃지 텍스트를 입력합니다.
예) 간 건강 관리 · 01
2
헤더 이미지 스타일 선택
헤더 이미지 스타일 선택 영역에서 원하는 스타일(A / A-1 / B)을 클릭합니다.
선택한 스타일이 GPT 이미지 생성의 기준 레퍼런스가 됩니다.
3
헤더 이미지 생성
헤더 이미지 영역의 프롬프트 입력란에 카드 제목이나 주제를 입력한 후 생성 버튼을 클릭합니다.
GPT API가 선택한 스타일 기반으로 헤더 이미지를 자동 생성합니다.
4
본문 캐릭터 선택 → 본문 이미지 생성
본문 캐릭터에서 남성 또는 여성을 선택한 후 본문 자동생성 버튼을 클릭하면 각 섹션 이미지가 자동으로 생성됩니다.

생성한 이미지를 편집기에 적용

상단 헤더 이미지 · 본문 섹션 일러스트 적용

  1. 생성된 이미지를 Ctrl+C로 복사합니다.
  2. 편집기에서 적용할 이미지 영역(헤더 또는 섹션)을 클릭합니다.
  3. Ctrl+V로 붙여넣거나, 이미지를 영역으로 드래그 앤 드롭합니다.
  4. 미리보기에서 이미지가 정상 반영되었는지 확인합니다.
이미지 붙여넣기(Ctrl+V)는 Chrome / Edge에서 정상 동작합니다. Safari에서는 드래그 앤 드롭을 사용하세요.
⚠️ API 키 입력란에 커서가 있는 상태에서는 Ctrl+V로 이미지가 붙여넣어지지 않습니다. 이미지 영역을 먼저 클릭한 뒤 붙여넣기 하세요.
5

최종 저장 및 전달

상단 저장 버튼

HTML 파일로 저장

  1. 편집기 우측 상단 [HTML 저장] 버튼을 클릭합니다.
  2. 저장 폴더를 먼저 선택합니다.
  3. 파일명을 확인·수정합니다. (확장자 .html 포함, 예: card07_수정본.html)
  4. 확인을 누르면 HTML 파일이 저장됩니다.
⚠️ 주의사항: Chrome 정책상 문서·다운로드·바탕화면 등 기본 폴더는 저장 위치로 선택할 수 없습니다. 그 안에 새 폴더를 만들거나 하위 폴더를 선택해주세요.
파일을 불러온 경우 원본 파일명이 기본값으로 표시됩니다. 저장된 HTML을 다시 브라우저에서 열면 편집을 이어서 할 수 있습니다.

이미지(JPG)로 저장

  1. 편집기 우측 상단 [IMAGE 저장] 버튼을 클릭합니다.
  2. 파일명을 확인·수정 후 저장합니다. (HTML 저장명 기준으로 자동 입력)
HTML 저장과 이미지 저장은 각각 별도로 진행합니다. 이미지는 화면 해상도의 3배 크기(고해상도)로 저장되어 카카오채널, 사내 게시물에 바로 첨부할 수 있습니다.

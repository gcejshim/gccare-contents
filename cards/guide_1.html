텍스트 수정

수정 방법

  1. 화면 왼쪽 편집 패널에서 수정할 섹션의 제목 또는 본문 텍스트를 클릭합니다.
  2. 내용을 직접 입력하면 오른쪽 미리보기에 실시간으로 반영됩니다.
  3. 줄바꿈은 Enter, 단락 구분은 빈 줄로 처리합니다.
수정 후 반드시 저장을 진행해야 변경사항이 유지됩니다. 브라우저를 닫으면 미저장 내용은 사라집니다.

섹션 이미지는 직접 생성 후 붙여넣기 또는 드래그 앤 드롭으로 적용하세요.

API 키 발급 방법

편집기02는 GPT (OpenAI) API로 헤더 이미지를 생성합니다. 아래에서 키를 발급받으세요.

🔑  GPT (OpenAI) — 헤더 이미지 생성
  1. platform.openai.com 접속 후 로그인 (OpenAI 계정 필요)
  2. 우측 상단 프로필 클릭 → API keys 선택
  3. Create new secret key 클릭 → 이름 입력 후 생성
  4. 표시된 키를 복사 (창 닫으면 다시 볼 수 없음)
  5. 편집기 상단 GPT 키 입력란에 붙여넣기 → API 키 저장
저장 성공 시 입력란이 ✓ GPT 키 저장됨으로 바뀝니다. 우측 ✕ 버튼으로 키를 삭제할 수 있습니다. 키는 브라우저에만 보관됩니다.
유료 서비스입니다. Billing 메뉴에서 크레딧을 충전해야 사용 가능합니다.

생성한 이미지를 편집기에 적용

상단 헤드 이미지 적용

  1. 생성된 이미지를 Ctrl+C로 복사합니다.
  2. 편집기 상단 헤드 이미지 영역을 클릭합니다.
  3. Ctrl+V로 붙여넣거나, 이미지를 영역으로 드래그 앤 드롭합니다.

본문 섹션 일러스트 적용

  1. 생성된 이미지를 Ctrl+C로 복사합니다.
  2. 편집기에서 교체할 섹션의 이미지 영역을 클릭합니다.
  3. Ctrl+V로 붙여넣거나 드래그 앤 드롭합니다.
  4. 미리보기에서 이미지가 정상 반영되었는지 확인합니다.
이미지 붙여넣기(Ctrl+V)는 Chrome / Edge에서 정상 동작합니다. Safari에서는 드래그 앤 드롭을 사용하세요.
⚠️ API 키 입력란에 커서가 있는 상태에서는 Ctrl+V로 이미지가 붙여넣어지지 않습니다. 이미지 영역을 먼저 클릭한 뒤 붙여넣기 하세요.

최종 저장 및 전달

상단 저장 버튼

HTML 파일로 저장

  1. 편집기 우측 상단 [HTML 저장] 버튼을 클릭합니다.
  2. 저장 폴더를 먼저 선택합니다.
  3. 파일명을 확인·수정합니다. (확장자 .html 포함, 예: card07_수정본.html)
  4. 확인을 누르면 HTML 파일이 저장됩니다.
파일을 불러온 경우 원본 파일명이 기본값으로 표시됩니다. 저장된 HTML을 다시 브라우저에서 열면 편집을 이어서 할 수 있습니다.

이미지(JPG)로 저장

  1. 편집기 우측 상단 [IMAGE 저장] 버튼을 클릭합니다.
  2. 파일명을 확인·수정 후 저장합니다. (HTML 저장명 기준으로 자동 입력)
HTML 저장과 이미지 저장은 각각 별도로 진행합니다. 이미지는 화면 해상도의 3배 크기(고해상도)로 저장되어 카카오채널, 사내 게시물에 바로 첨부할 수 있습니다.
